# 📘 Tarefa: Jogo da Forca

## 🎯 Objetivo

Pratique o uso de strings, laços de repetição, condicionais e entrada de dados em Python criando um jogo da Forca.

## 📝 Tarefas

### 🛠️ Implementar o Jogo da Forca

#### Descrição

Crie um jogo em que o jogador tenta adivinhar uma palavra secreta, informando uma letra por vez. As letras corretas revelam suas posições na palavra; os erros reduzem o número de tentativas disponíveis.

#### Requisitos

O programa completo deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Exibir a palavra oculta como espaços reservados (por exemplo, `_ _ _ _`).
- Solicitar palpites de uma letra e atualizar a exibição para revelar as letras acertadas.
- Controlar e informar o número de tentativas incorretas restantes.
- Encerrar quando o jogador adivinhar a palavra ou esgotar as tentativas.
- Exibir uma mensagem indicando se o jogador venceu ou perdeu.
